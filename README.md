# SP_LAB_3 — Syntax Analyzer

## Опис проєкту

Синтаксичний аналізатор спрощеної C-подібної мови програмування, реалізований на C++17 із використанням Flex та Bison

Проєкт підтримує лексичний і синтаксичний аналіз, побудову абстрактного синтаксичного дерева (AST), виконання програм та візуалізацію AST за допомогою Graphviz

## Технології

- C++17
- Flex
- Bison
- CMake
- Graphviz
- Visual Studio 2026

## Підтримувані конструкції

- Оголошення цілих змінних
- Присвоювання значень
- Арифметичні операції `+`, `-`, `*`, `/`
- Порівняння `==`, `!=`, `<`, `>`, `<=`, `>=`
- Умовні оператори `if/else`
- Виведення значень через `print()`
- Завершення виконання через `return`

Реалізовано підмножину синтаксису C, а не повну граматику стандарту C

## Архітектура

1. `lexer.l` — лексичний аналізатор Flex
2. `parser.y` — граматика та семантичні дії Bison
3. `ast.h` — класи вузлів AST, інтерпретація та експорт дерева
4. `SP_LAB_3.cpp` — точка входу програми
5. `CMakeLists.txt` — конфігурація збірки

## Приклад

```c
int main() {
    int a = 10;
    int b = 20;

    if (a < b) {
        print(a + b);
    }

    return 0;
}
```

Результат:

```text
Syntax analysis: SUCCESS

Program output:
30

Program return value: 0
```

## Візуалізація AST

Після успішного синтаксичного аналізу програма експортує AST у формат DOT

Для створення SVG:

```powershell
dot -Tsvg ast.dot -o ast.svg
```

Команду потрібно запускати в директорії, де створено `ast.dot`, або вказати повний шлях

## Тестування

У директорії `tests` розміщуються приклади коректних програм і програми з навмисними синтаксичними та семантичними помилками
